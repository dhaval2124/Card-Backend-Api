# Config Server - Card Management System

This is the centralized configuration server for the Card Management System microservices architecture.

## Features

- Centralized configuration management
- Git-based configuration storage
- Service discovery with Eureka
- Security with basic authentication
- Health monitoring with Actuator
- Docker support

## Prerequisites

- Java 17
- Maven 3.6+
- Docker (optional)
